# Expense Tracker Web Application

## Project Description ##
The Expense Tracker is a simple and user-friendly web application that helps users keep track of their daily expenses. Users can enter expense details such as category, amount, and date. The entered expenses are displayed in a table, and the total expense amount is automatically calculated and updated in real time.

This project was developed as part of the **Full Stack Development** course in the **MCA program** to understand basic frontend development concepts and teamwork using Git.

---

## Technologies Used ##
- HTML5 for creating the structure of the web page  
- CSS3 for styling and layout  
- JavaScript for handling logic, validation, and dynamic updates using DOM manipulation
